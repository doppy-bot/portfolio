Unsupervised Learning • Risk Segmentation

Credit Risk Segmentation (EDA + K-Means)

Problem: No “default” label available — needed a way to understand risk patterns without supervised prediction.

Approach: Cleaned and explored a Kaggle dataset (51,336 customers), ran correlation checks, built a K-Means model (k=4), visualised clusters with PCA, and created a simple risk scoring approach.

Outcome: Segmented customers into Low, Medium, High, and No Credit History groups to support decision-making.

Impact Segmented 51,336 customers into 4 risk profiles to support decision-making without default labels.

Fairness • Responsible AI

Fairness & Bias in Income Prediction

Problem: Accuracy alone can hide harm — evaluated whether an income model treats demographic groups differently.

Approach: Built a baseline Logistic Regression model and evaluated fairness using Demographic Parity, Disparate Impact Ratio, and Equal Opportunity. Then ran an intersectional analysis (Gender × Race).

Key finding: Observed unequal selection rates and differing true positive rates across groups, with compounded disadvantage in intersectional slices.

Key Finding Identified unequal selection rates across demographic groups using parity and equal-opportunity metrics.

Python Logistic Regression Fairness Metrics Intersectional Analysis

Forecasting • Simulation

Premier League Table Prediction (API + Monte Carlo)

Problem: Forecast end-of-season outcomes using match history + remaining fixtures.

Approach: Pulled match data via football-data.org API, engineered rolling performance features, trained a Random Forest classifier for match outcome probabilities, then ran a Monte Carlo simulation (5,000 runs).

Output: Title / Top-4 / Relegation probabilities + scenario-based visualisations.
