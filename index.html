Credit Risk • Explainable AI

Credit Risk Decision System (XGBoost + SHAP)

Problem: A default-risk model is only useful if a credit team can trust and act on it — a black-box score isn't enough.

Approach: Engineered features from credit bureau data, trained an XGBoost model to predict Probability of Default, and wrapped it in a business decision engine (Approve / Reject) with SHAP-based explainability behind every call.

Outcome: Shipped as an interactive Streamlit dashboard, so a reviewer sees not just the decision but why — which features pushed a case toward approval or rejection.

Impact ROC-AUC ≈ 0.75 predicting default, with every decision traceable to SHAP-ranked features in a live approve/reject dashboard.

Analytics Engineering • Experimentation

Payment Analytics — Fraud-Check A/B Test Pipeline

Problem: A payments company rolled out a new fraud-check flow to 50% of customers — did it actually cut fraud, and did it cost too many good payments along the way?

Approach: Built a tested, version-controlled dbt warehouse (staging → dimensional marts) over 120K transactions on DuckDB, with 24 passing data tests, then ran proper two-proportion z-tests with confidence intervals and a guardrail metric.

Outcome: A dashboard framing the result as a business trade-off rather than an automatic ship decision.

Result Cut approved-transaction fraud by 46% relative (z=−10.4, p<0.001) — against a 2.95-point drop in approval rate the business had to weigh.

dbt DuckDB SQL Python (SciPy)

GenAI • LLM Application

RAG Finance Assistant (LangChain + LLaMA 3.2)

Problem: Asking an LLM to recall project details from training data invites vague, unsourced answers.

Approach: Built a fully local retrieval-augmented generation pipeline — a FAISS vector store over four project documents, a prompt builder that injects the retrieved context, and generation via LLaMA 3.2 through Ollama. Zero cloud dependency, zero API cost.

Outcome: Every answer traces back to a real source document — the same retrieve → augment → generate pattern used in conversational analytics tools.
